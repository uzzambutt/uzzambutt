### ⚡ What I Actually Build

```text
 FPGA    ▸  custom dev boards, RTL in Verilog/VHDL, timing closure, DDR & high-speed IO
 RF      ▸  front-ends, LNAs, matching networks, antennas, spectrum work on SDR
 GNSS    ▸  GPS/GNSS receivers, NMEA & raw-observable pipelines, timing/PPS discipline
 ESP32   ▸  ESP-IDF firmware, FreeRTOS tasks, BLE/Wi-Fi/LoRa links, deep-sleep power budgets
 PCB     ▸  multilayer layout, impedance control, DFM, bring-up and bench debug
```
